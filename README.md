## Run locally

This is a static HTML, CSS, and JavaScript website. No package
installation or build step is required.

1.  Clone the repository:

    ``` bash
    git clone https://github.com/rajanakmanivardhan/Manivardhanrajank.-Portfolio.git
    ```

2.  Open the project folder:

    ``` bash
    cd Manivardhanrajank.-Portfolio
    ```

3.  Open `index.html` in a browser.

You can also use a local development server, for example:

``` bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1.  Push the website files to the repository's `main` branch.
2.  In GitHub, open **Settings → Pages**.
3.  Under **Build and deployment**, select **Deploy from a branch**.
4.  Select the `main` branch and the `/ (root)` folder.
5.  Save the settings and wait for GitHub Pages to publish the site.
6.  Open the live portfolio URL shown in the Pages settings.

For future updates, commit and push the revised files to the configured
branch.

## Add your resume PDF

To make the resume available from the portfolio:

1.  Export your latest resume as a PDF.
2.  Name the file `resume.pdf`.
3.  Add it to the repository root (the same folder as `index.html`).
4.  Update the Resume section in `index.html` to link to `resume.pdf`.
5.  Commit and push the change.

Only publish a current resume that you are comfortable making public.
Check phone number, email, links, and education details before
uploading.
