# Rajanak Manivardhan — Portfolio

A responsive personal portfolio focused on entry-level Linux System Administration, IT Operations and Cloud Support opportunities.

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your repository's `main` branch.
2. Ensure `index.html` is in the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Wait for the deployment and test the published URL on desktop and mobile.

## Before publishing
- Verify the name spelling against official certificates.
- Verify CGPA, degree dates and diploma details.
- Add genuine project screenshots and direct repository URLs.
- Update project status as work is completed. Do not claim planned work as completed.
- Add only certifications actually earned.
- Keep the resume PDF current.
- Test email, LinkedIn, GitHub and resume links.

## Structure
- `index.html` — portfolio content
- `assets/css/style.css` — responsive styling and themes
- `assets/js/script.js` — theme and mobile navigation
- `assets/resume/Manivardhan_Resume.pdf` — downloadable resume
