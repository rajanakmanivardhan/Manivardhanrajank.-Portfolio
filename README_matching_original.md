## Run locally

This is a static website; no package installation or build process is required.

```bash
git clone https://github.com/rajanakmanivardhan/Manivardhanrajank.-Portfolio.git
cd Manivardhanrajank.-Portfolio
```

Open `index.html` in a browser, or start a simple local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy with GitHub Pages

1. Push `index.html` to the repository's `main` branch.
2. Open **Settings → Pages** in GitHub.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.
