## Run locally

1.  Clone the repository:

    ``` bash
    git clone https://github.com/rajanakmanivardhan/Manivardhanrajank.-Portfolio.git
    ```

2.  Open the project folder:

    ``` bash
    cd Manivardhanrajank.-Portfolio
    ```

3.  Start a local web server:

    ``` bash
    python3 -m http.server 8000
    ```

4.  Visit `http://localhost:8000` in your browser.

You can also open `index.html` directly in a browser. A local server is
recommended for a more consistent test.

## Deploy with GitHub Pages

1.  Upload `index.html` to the root of this repository.
2.  Commit the file to the `main` branch.
3.  Open **Settings → Pages** in GitHub.
4.  Under **Build and deployment**, select **Deploy from a branch**.
5.  Select branch `main` and folder `/ (root)`.
6.  Click **Save** and wait for GitHub Pages to finish publishing.
7.  Open the live website URL shown in the Pages settings.

The homepage file must be named exactly `index.html` and must be in the
repository root, not inside a nested folder.
